# 追記: 富士山可視予報ツール（2026-09-29 実装）

## 何を作ったか

`/guide` に「あなたの列車から富士山が見えるか」を答えるツールを追加。
出発地（東京／京都／新大阪）・日付（10日先まで）・出発時刻を選ぶと、
その列車が富士山区間に達する時刻と、**その時刻の空の予報**を返す。

| ファイル | 役割 |
|---|---|
| `lib/fuji-window.ts` | 所要時間モデルと判定（純関数・テスト対象） |
| `app/api/fuji-window/route.ts` | Open-Meteo から10日×時間別の雲量・降水（1時間キャッシュ） |
| `components/travel/FujiWindowForecast.tsx` | UI |
| `messages/*.json` の `fujiWindow` | 24キー × 9言語 |

## 設計の根拠

- **再訪の理由になる**: 予報は毎日変わるので、同じ読者が予約後・前日・当日朝と見に来る。
  現状のリピート率0.5%（2,621人中 新規2,607人）に対する打ち手。
- **SERPで代替できない**: 日付・時刻・方向の組み合わせなので、一行の抜粋にならない。
- **購入の瞬間に繋がる**: 曇る便には「{time}発なら晴れる」を出し、その隣に切符リンクを置く。

## 数値の根拠

- 富士山区間は東京から約42分（新富士付近）。東行きは到着の約42分前＝
  京都発91分後・新大阪発105分後。**のぞみ基準**で、UIにもその旨を明記。
- 判定閾値は既存のトップページ・ウィジェットと同一（雲量30%以下=high、70%以下=medium）。
  **同じ空について2つの数字が出ないようにするため。**
- 降水0.5mm以上は雲量に関わらず low。

## 計測

新しい placement:

- `fuji_window_check`（cta_click）— ツールを実行した
- `fuji_window_result`（affiliate_cta_view / affiliate_click）— 結果のKlook導線

Klookリンクは `getDirectionTicketLink()` を再利用し、東京発→1443754、
京都・新大阪発→1443748 の区間リンクに出し分ける。
