# fujiseat 開発ロードマップ（2026-11-20 時点）

リポジトリと公開サイトを確認して書いています。効果・収益はまだ測っていないものを含むので、断定できないものは「検証待ち」としました。難易度は S / M / L の3段階です。
目標は、既存の14路線で「探せる → 分かる → 乗れる → 必要なら予約できる」をつなげることです。

| 項目 | 現在の実装 | 確認した課題 | 利用者にとっての価値 | 難易度 | 必要なデータ・外部依存 | SEO・収益への影響 | 優先度 |

## 次の順番

1. GA4 にカスタムディメンションを登録し、11/29 の測定をする（比べられる指標は docs/ANALYTICS.md）。
2. 11/29 のあと、トップ・メニューから /scenic への入口を足す。トップの画像表記も読みやすくする。
3. 各路線に「主要都市からの行き方」を1行ずつ足す（公式の経路だけ使い、運賃は書かない）。
4. Booking.com のアフィリエイトURLを発行したら、シートから反映する。
5. 2027年3月の時刻表改正の前に、時刻データを点検する仕組みを作る。
