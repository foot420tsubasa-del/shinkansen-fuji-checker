## 次の順番

1. GA4 にカスタムディメンションを登録し、11/29 の測定をする（比べられる指標は docs/ANALYTICS.md）。
2. 11/29 のあと、トップ・メニューから /scenic への入口を足す。トップの画像表記も読みやすくする。
3. 各路線に「主要都市からの行き方」を1行ずつ足す（公式の経路だけ使い、運賃は書かない）。
4. Booking.com のアフィリエイトURLを発行したら、シートから反映する。
5. 2027年3月の時刻表改正の前に、時刻データを点検する仕組みを作る。

## 2026-11-20 追記：「Plan this ride」と次の開発の評価

### 3路線を選んだ根拠
- Search Console（2026-10-20〜11-17）では、/scenic 配下の表示回数は0でした。15〜18日に公開したばかりで、まだ表示されていません。関連する検索語は「hokuriku shinkansen seat map」20回、「tohoku shinkansen seat map」10回だけです。
- 需要から優先路線を決められないため、公式情報を確認でき、既存の予約商品と対応する3路線にしました：江ノ電、嵯峨野、ゆりかもめ。
- 箱根登山鉄道は、公式の Hakone Navi が 504 エラーで読めず、見送りました（経路検索サイトの運賃は使いません）。黒部峡谷鉄道は、公式サイトがメンテナンス中で運賃を確認できず、見送りました。

### 残る11路線への展開
1. 箱根登山・黒部：公式サイトが復旧したら、運賃・所要時間・フリーパスの条件を確認して追加する（データの形は同じ）。
2. 新幹線4路線（東海道・北陸・東北・上越）
   - JR東日本の公式サイトは自動取得で403になるため、運賃は記載しない、またはブラウザで確認する。
   - 所要時間は既存の時刻データ（公式時刻表）から出せる。
3. 富士急・五能線（リゾートしらかみ）・只見・釧網・富良野：季節列車と普通列車の区別が要る。validUntil で期限を管理する（流氷物語は2027年2月末など）。
4. 1路線あたり：公式ページ3〜5枚の確認、データ1件、テストは自動。目安は1路線30〜60分。
