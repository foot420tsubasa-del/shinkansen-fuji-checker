# Scenic route image prompts

Each prompt stands alone: paste it as is.
- Size: wide images are 1536×1152, tall images are 1152×1536 (4:3, multiples of 16).
- Save as PNG into `public/images/scenic/` under the file name given. Claude converts it to WebP (300 KB or less) and links it to the page.
- The page labels every image "Illustrative image", so a generated image is fine.
- Check that nothing in the image looks wrong for the real place.
