# 車窓検索の改善

## 実装

- トップは駅名からの検索と、景色から路線を探す入口を分けました。景色のショートカットは既存の `/scenic` へ進みます。
- 駅名の候補はタップとキーボードで選べます。検索済みの駅名は結果と共有URLにそろえています。
- 要約には該当する車窓、左右、確認済みの座席情報、見える区間、出発からの概算、景色の時期と根拠を表示します。詳細な時刻・地図・予約案内は従来のデータとコンポーネントを使用します。
- 広島方面へ続く旅程では、収録済みの東海道区間を別の検索として案内します。未収録区間の景色や所要時間は生成しません。
- 景色一覧は公開済み14路線から、景色・地域・季節の条件を同時に適用します。紅葉や花の時期は元のガイド本文にある情報を使い、運行日は別の注記で案内します。
- トップ・一覧・路線詳細のURL、canonical、hreflang、構造化データと、既存のアフィリエイト導線を維持します。

## 検証・リリース

- 作業ブランチは `codex/scenic-search-experience`。375pxで東京→京都、江ノ電、東京→広島から収録済み区間への移動を確認。1280pxでトップの海リンク、北海道・冬・雪の組み合わせ、夏の空結果と解除を確認しました。
- 追加した検索用の15項目は9言語すべてに登録しました。翻訳全体の監査は、従来から英語のままの固有名詞や旧ページの文言も報告します。
- Suica記事の既存のJSX引用符を修正し、全体の lint が通るようにしました。
- 通常の公開は Vercel の `main` 自動デプロイを使います。公開後は検索・景色フィルター・詳細・ガイドの応答を再確認します。
- 公開版の動作に重大な問題がある場合は、原因を修正するか対象コミットを revert します。

## 残課題

- 複数路線をまたぐ全旅程や、山陽新幹線内の車窓情報には別途裏付けが必要です。
- 車窓のタイミングはモデルと参照列車による概算です。運行可否、天候、開花、積雪などの当日状況は各運行会社や現地の案内を確認してください。
- 一覧とルートデータの本文は従来どおり英語中心です。トップの検索ラベルと操作は既存の9言語に対応しています。
